# ZERO//ANTE — ROGUE HOLD'EM

6人卓のテキサスホールデムに、ローグライクの能力ドラフトを重ねたブラウザゲーム。
**回戦数を決めて始め、終わった時いちばんチップを持っていた人が勝ち。**

▶ **[遊ぶ](https://ck59cydsrh-del.github.io/zero-ante/)**

---

## 何が起きるゲームか

- **チップは体力であり、賭け金であり、能力を買う金でもある。** 減らせば脱落し、
  賭ければ増え、店では消える。1つの数字が3つの役目を持つ
- **1回戦ごとに能力が1つ配られる。** 3択から選ぶか、見送るか（SCRAP +1）
- **同じ系統を2枚・3枚と重ねると、その系統の効果が無料で付く**（系統シナジー）。
  強い1枚を拾うか、系統を寄せて土台を作るか——ここが組み方になる
- 2回戦ごとに参加額が上がり、切れ目に **BACK ROOM** が開く。能力を買い、売り、引き直す

能力は **52種**。ヒント / 守り / 相手を妨害 / カード・ルール変更 の4系統。

| 系統 | ×2 | ×3 |
|---|---|---|
| 相手を妨害 | **追撃** 当てるたび +250枚 | **制圧** 毎回1発、使い切りが減らない |
| 守り | **盾** 毎回1発、妨害を受け流す | **要塞** 手札も場札も書き換えられない |
| カード・ルール変更 | **変異** 低い手札を引き直す | **暴走** 手札が3枚 |
| ヒント | **観測** 次の場札が常に見える | **透視** 相手1人の手札が公開 |

## 遊び方

1. 対戦モードと回戦数（3 / 6 / 9 / 12）を選ぶ
2. 開始チップ 7,500枚。最後の回戦を終えた時点で最多チップなら勝ち
3. 途中でチップが0になったらそこで脱落。全員飛ばせばその場で勝ち

画面内の「遊び方 [?]」に、ANTE・SB/BB・ディーラー・役の強さまで全部書いてあります。

## 対戦

| モード | できること |
|---|---|
| ひとりで潜る | 6人卓を CPU 相手に |
| みんなで遊ぶ | 1台を回して複数人で |
| **別の端末と対戦** | **2台で同じ合言葉を入れるだけ**でつながる |

ローカル通信は WebRTC の直結で、**中継サーバを置いていません**。
PeerJS の公開ブローカーに `zero-ante-<合言葉>` という id で部屋を開き、
相手が同じ id につなぎます。卓はホスト側が持ち、
ゲストの画面には**自分の手札しか送られません**。
合言葉でつながらない回線のために、合図コードを手渡しする道も残してあります。

## 手元で動かす

素の HTML / CSS / JavaScript だけです。ビルドも依存も要りません。

```bash
npm run dev     # http://localhost:4173 で配る
npm test        # ヘッドレスの検証（120件）
```

`npm test` は仮想時計を積んだ最小 DOM（`tests/dom-stub.cjs`）の上で
`game.js` をそのまま走らせます。1ランが数ミリ秒で終わるので、
**能力52種すべての発火・卓が必ず終わること・配当の順序**まで毎回検査できます。

## 対応

デスクトップと縦持ちの端末（600px 以下は席を3列に畳む別レイアウト）。

`prefers-reduced-motion` で演出は止まります。
